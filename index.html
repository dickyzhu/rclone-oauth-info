rclone 个人云盘同步

本应用是账户所有者使用开源工具 rclone 建立的个人同步配置，用于将本人 OneDrive 中指定目录的文件同步到本人 Google Drive 中指定的目标目录。

此站点仅提供应用说明，不提供登录、上传、授权回调或令牌接收功能。维护者在本机或 GitHub Actions 中运行同步任务。

Google Drive 权限用途

在用户授权的范围内，rclone 读取文件元数据以比较同步状态，按同步配置创建、上传或更新目标文件。镜像同步也可能移动、备份或删除目标目录内的项目，具体取决于运行参数和删除限制。

运行方式

Google 账户通过 Google 的 OAuth 授权流程授权。授权信息保存在维护者自己的 rclone 配置或 GitHub Actions Secrets 中。本说明站点不连接这些配置。

数据与使用说明

请阅读隐私政策及使用条款。如需联系维护者，请使用 Google 授权页面列出的用户支持邮箱。
