应用说明隐私政策使用条款

隐私政策

本说明适用于账户所有者运行的 rclone 个人 OneDrive → Google Drive 同步配置。

访问和使用的数据

同步程序访问用户授权范围内的 Google Drive 文件及其元数据，包括名称、路径、大小、修改时间和可用校验信息，以比较文件状态并维护指定目标目录。根据同步设置，程序可能创建、更新、移动、备份或删除目标项目。文件内容和元数据仅用于维护者发起或配置的同步任务。

运行和存储位置

同步任务运行在维护者自己的电脑或 GitHub Actions 运行器上；同步目标文件存储在 Google Drive 中。运行器可能使用临时文件或内存缓冲区处理数据。OAuth 授权信息保存在维护者的本机 rclone 配置或 GitHub Actions Secrets 中；工作流运行时会生成权限受限的临时配置，并在结束时清理临时配置。

服务提供方和日志

执行同步需要使用 Microsoft OneDrive、Google Drive；使用 GitHub Actions 时，任务还在 GitHub 的运行环境中处理数据。上述服务各自的隐私条款适用。同步日志可能保留文件名、路径、错误信息及传输统计；维护者应避免公开包含私人文件信息的日志。

数据使用范围

本同步配置用于个人文件同步，不包含广告、出售用户数据或利用文件内容训练模型的功能。此说明站点不收集云盘文件、密码、OAuth 密钥或令牌，也不提供数据提交表单。网站托管服务可能记录常规访问日志。

停止访问和数据管理

维护者可停止工作流，并在 Google 账户的第三方应用访问设置中撤销授权。撤销授权不会自动删除已经同步的文件；文件与备份应由维护者在相应云盘中管理。维护者也可以删除本机配置、GitHub Secret 和不再需要的工作流日志。

联系

请使用 Google 授权页面列出的用户支持邮箱联系应用维护者。
